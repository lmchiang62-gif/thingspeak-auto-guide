ThingSpeak_Auto 自動同步教學

把 ThingSpeak 頻道 3430234 的環境資料，每 5 分鐘自動寫入 Google 試算表。

一、建立 Google 試算表

1
開啟 Google 試算表，建立一份新試算表。
2
從網址複製試算表 ID。網址中 /d/ 與 /edit 之間的文字就是 ID。
3
本教學會自動建立一個名為 ThingSpeak_Auto 的新分頁。
本範例的 ThingSpeak 頻道 ID 是 3430234，CO₂ 在 field3。

二、建立 Apps Script

1
在試算表選擇「擴充功能」→「Apps Script」。
2
刪除編輯器裡原本的程式碼，貼上下一節的完整程式。
3
把 SHEET_ID 換成你自己的試算表 ID，按儲存。

三、完整 Apps Script 程式

const CHANNEL_ID = '3430234';
const SHEET_ID = '請替換成你的 Google 試算表 ID';
const SHEET_NAME = 'ThingSpeak_Auto';
const FEED_URL =
  'https://api.thingspeak.com/channels/' + CHANNEL_ID + '/feeds.json?results=1';

function getSpreadsheet() {
  return SpreadsheetApp.openById(SHEET_ID);
}

function setup() {
  const spreadsheet = getSpreadsheet();
  let sheet = spreadsheet.getSheetByName(SHEET_NAME);
  if (!sheet) sheet = spreadsheet.insertSheet(SHEET_NAME);

  if (sheet.getLastRow() === 0) {
    sheet.appendRow([
      'ThingSpeak entry_id', '時間', '溫度 (°C)', '濕度 (%)', 'CO₂ (ppm)',
      'PM2.5', 'PM10', 'TVOC', 'NOX', '照度'
    ]);
  }

  // 避免重複建立觸發器
  ScriptApp.getProjectTriggers().forEach(function(trigger) {
    if (trigger.getHandlerFunction() === 'syncThingSpeak') {
      ScriptApp.deleteTrigger(trigger);
    }
  });

  ScriptApp.newTrigger('syncThingSpeak')
    .timeBased()
    .everyMinutes(5)
    .create();

  // 建立完成後立即抓一次最新資料
  syncThingSpeak();
}

function syncThingSpeak() {
  const response = UrlFetchApp.fetch(FEED_URL, {
    muteHttpExceptions: true
  });
  if (response.getResponseCode() !== 200) {
    throw new Error('ThingSpeak 回應錯誤：' + response.getResponseCode());
  }

  const data = JSON.parse(response.getContentText());
  if (!data.feeds || data.feeds.length === 0) {
    throw new Error('沒有 ThingSpeak 資料');
  }

  const sheet = getSpreadsheet().getSheetByName(SHEET_NAME);
  const feed = data.feeds[0];
  const lastId = sheet.getLastRow() > 1
    ? String(sheet.getRange(sheet.getLastRow(), 1).getValue())
    : '';

  // 同一筆資料不重複寫入
  if (String(feed.entry_id) === lastId) return;

  const timezone = getSpreadsheet().getSpreadsheetTimeZone() || 'Asia/Taipei';
  const time = Utilities.formatDate(
    new Date(feed.created_at), timezone, 'yyyy-MM-dd HH:mm:ss'
  );

  sheet.appendRow([
    feed.entry_id, time, feed.field1, feed.field2, feed.field3,
    feed.field4, feed.field5, feed.field6, feed.field7, feed.field8
  ]);
}

四、第一次執行與授權

1
上方函式選單選擇 setup，按「執行」。
2
按「審查權限」，選擇你的 Google 帳號。
3
若出現「這個應用程式未經 Google 驗證」，按「進階」→「前往未命名的專案」→「允許」。
完成授權後，程式會建立 ThingSpeak_Auto 分頁，並立即寫入最新一筆資料。

常見錯誤

Cannot read properties of null (reading 'getSheetByName')
通常是使用了 getActiveSpreadsheet()。本教學改用 SpreadsheetApp.openById(SHEET_ID)，並且必須填入正確的試算表 ID。
資料重複
確認程式只保留一個 syncThingSpeak 觸發器；重新執行 setup 會先刪除舊觸發器再建立一個新的。
空白資料
先確認 ThingSpeak 頻道有公開資料，並用這個網址測試：
https://api.thingspeak.com/channels/3430234/feeds.json?results=1
