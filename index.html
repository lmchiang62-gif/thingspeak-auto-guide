ThingSpeak 自動同步教學

把 ThingSpeak 頻道 3430234 的最新環境資料，每 5 分鐘自動寫入 Google 試算表。

完成後的資料流程

ThingSpeak
頻道 3430234
Apps Script
每 5 分鐘執行
Google 試算表
ThingSpeak_Auto

一、建立 Google 試算表

1
開啟 Google 試算表，建立一份新試算表。
2
從網址複製試算表 ID。網址格式是 https://docs.google.com/spreadsheets/d/試算表ID/edit，只複製 /d/ 和 /edit 之間的文字。
3
分頁名稱會由程式自動建立為 ThingSpeak_Auto，不要手動輸入資料欄位。
本教學使用 ThingSpeak 頻道 3430234；CO₂ 數值在 field3。

二、建立 Apps Script

1
在試算表上方選單點「擴充功能」→「Apps Script」。
2
刪除編輯器原本的程式，完整貼上下面的程式。
3
把程式第 2 行的 SHEET_ID 替換成剛才複製的試算表 ID，然後按儲存。

三、貼上正確程式

const CHANNEL_ID = '3430234';
const SHEET_ID = '請替換成你的 Google 試算表 ID';
const SHEET_NAME = 'ThingSpeak_Auto';
const FEED_URL = 'https://api.thingspeak.com/channels/' + CHANNEL_ID + '/feeds.json?results=1';

function getSpreadsheet() {
  return SpreadsheetApp.openById(SHEET_ID);
}

function setup() {
  const spreadsheet = getSpreadsheet();
  let sheet = spreadsheet.getSheetByName(SHEET_NAME);
  if (!sheet) sheet = spreadsheet.insertSheet(SHEET_NAME);

  if (sheet.getLastRow() === 0) {
    sheet.appendRow([
      'ThingSpeak entry_id', '時間', '溫度 (°C)', '濕度 (%)', 'CO₂ (ppm)',
      'PM2.5', 'PM10', 'TVOC', 'NOX', '氣壓'
    ]);
  }

  ScriptApp.getProjectTriggers().forEach(function(trigger) {
    if (trigger.getHandlerFunction() === 'syncThingSpeak') {
      ScriptApp.deleteTrigger(trigger);
    }
  });

  ScriptApp.newTrigger('syncThingSpeak')
    .timeBased()
    .everyMinutes(5)
    .create();

  syncThingSpeak();
}

function syncThingSpeak() {
  const response = UrlFetchApp.fetch(FEED_URL, {muteHttpExceptions: true});
  if (response.getResponseCode() !== 200) {
    throw new Error('ThingSpeak 回應錯誤：' + response.getResponseCode());
  }

  const data = JSON.parse(response.getContentText());
  if (!data.feeds || data.feeds.length === 0) {
    throw new Error('沒有 ThingSpeak 資料');
  }

  const spreadsheet = getSpreadsheet();
  const sheet = spreadsheet.getSheetByName(SHEET_NAME);
  if (!sheet) throw new Error('找不到工作表：' + SHEET_NAME);

  const feed = data.feeds[0];
  const lastId = sheet.getLastRow() > 1
    ? String(sheet.getRange(sheet.getLastRow(), 1).getValue())
    : '';
  if (String(feed.entry_id) === lastId) return;

  const timezone = spreadsheet.getSpreadsheetTimeZone() || 'Asia/Taipei';
  const time = Utilities.formatDate(
    new Date(feed.created_at), timezone, 'yyyy-MM-dd HH:mm:ss'
  );
  sheet.appendRow([
    feed.entry_id, time, feed.field1, feed.field2, feed.field3,
    feed.field4, feed.field5, feed.field6, feed.field7, feed.field8
  ]);
}

四、授權並建立自動執行

1
在 Apps Script 上方函式選單選 setup，按「執行」。
2
第一次會跳出授權畫面：選擇你的 Google 帳號 →「進階」→「前往專案」→「允許」。
3
回到 Apps Script 左側「觸發條件」，確認有一筆 syncThingSpeak，事件來源是「時間驅動」，頻率是「每 5 分鐘」。
setup 執行成功後，會建立 ThingSpeak_Auto 分頁，並立即寫入最新一筆資料；之後每 5 分鐘抓取一次。

五、確認是否正常

1
回到 Google 試算表，重新整理頁面，開啟 ThingSpeak_Auto 分頁。
2
Apps Script 左側「執行項目」應看到 syncThingSpeak 每 5 分鐘顯示「已完成」。
3
每一列的第一欄是 ThingSpeak 的 entry_id；相同編號不會重複寫入。
欄位來源
時間ThingSpeak created_at，轉成試算表時區
CO₂field3
PM2.5～NOXfield4～field7

常見問題

Cannot read properties of null (reading 'getSheetByName')
代表仍在使用 getActiveSpreadsheet()。請改用本頁的 SpreadsheetApp.openById(SHEET_ID)。
沒有新增資料
先看「執行項目」是否顯示錯誤，再確認 ThingSpeak 的最新 entry_id 是否已變更；若編號相同，程式會刻意不重複寫入。
觸發器不見了
重新執行一次 setup，它會刪除舊的 syncThingSpeak 觸發器並重新建立每 5 分鐘觸發器。
